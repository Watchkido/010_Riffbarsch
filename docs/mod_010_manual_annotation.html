🔬 Manual Annotation (Mod 010)

mod_010_fotos_haendisch_einteilen.py - Interaktive Bildklassifikation für Training Data

🎯 Modulüberblick

Dieses Modul implementiert eine Manual Annotation Pipeline für die Vorbereitung von Trainingsdaten in einem Computer Vision Projekt.

Manual Annotation: Der Prozess, bei dem Menschen Bilder manuell klassifizieren und mit Labels versehen. Das ist wie das Sortieren von Fotos in verschiedene Alben - nur dass die Entscheidungen später zum Training von KI-Modellen verwendet werden.

🔧 Technische Konzepte

  • Ground Truth Generation Erstellen der "richtigen Antworten"
  • Binary Classification Zwei-Klassen-System Setup
  • Interactive Processing Benutzer-gesteuerte Klassifikation
  • File Organization Automatisches Sortieren der Bilder

⚙️ Workflow im Detail

1
File System Scanning: Durchsuchen des Quellordners nach Bilddateien (JPG, PNG, DNG)
2
Image Loading & Preprocessing: Laden und Verkleinern der Bilder mit OpenCV
3
Interactive Classification: Anzeige des Bildes und Warten auf Benutzereingabe
4
Automated File Organization: Verschieben in entsprechende Zielordner
Supervised Learning Preparation: Die manuelle Klassifikation erstellt die Grundlage für "überwachtes Lernen" - die KI braucht einen menschlichen Experten, der ihr zeigt, was auf den Bildern zu sehen ist.

🎮 Benutzersteuerung

⌨️ Tastenbefehle:

T = Riffbarsch/Taucher erkannt → Verschieben nach "riffbarsch"

K = Kein Riffbarsch → Verschieben nach "kein_riffbarsch"

Q = Programm beenden

Binary Classification Setup: Das System teilt Bilder in genau zwei Kategorien ein - "Riffbarsch vorhanden" oder "Kein Riffbarsch". Wie ein digitales Ja/Nein-Entscheidungsspiel für jedes Bild.

💡 Warum ist das wichtig?

  • Data Quality: Hochwertiges, manuell überprüftes Trainingsmaterial
  • Class Balance: Gleichmäßige Verteilung beider Kategorien
  • Domain Expertise: Menschliche Intelligenz zur Qualitätssicherung
  • Training Foundation: Grundlage für alle nachfolgenden ML-Modelle

📁 Ordnerstruktur

data/ ├── raw/ # Originalbilder (Input) │ ├── IMG_001.jpg │ ├── IMG_002.png │ └── IMG_003.DNG └── processed/ ├── riffbarsch/ # Positive Samples (T-Taste) │ ├── riff_001.jpg │ └── riff_002.png └── kein_riffbarsch/ # Negative Samples (K-Taste) ├── empty_001.jpg └── empty_002.png
Ground Truth Generation: Durch die manuelle Klassifikation entstehen die "richtigen Antworten" (Ground Truth) für das Machine Learning Training. Diese Daten sind das Gold des maschinellen Lernens - ohne sie kann kein zuverlässiges Modell trainiert werden.
⚠️ Qualitätskontrolle: Die Qualität der manuellen Annotation bestimmt direkt die Qualität des späteren KI-Modells. Sorgfältige und konsistente Klassifikation ist entscheidend für den Erfolg aller nachfolgenden Trainingsschritte.
