🎯 Was ist Instance Segmentation?

Dieses Modul implementiert Mask R-CNN Instance Segmentation für pixel-genaue Objekterkennung und Klassifikation von Riffbarschen und Tauchern.

Einfach erklärt: Während normale Objekterkennung nur rechteckige Kästen um Objekte zeichnet, erstellt Instance Segmentation pixel-genaue Masken - wie das perfekte Ausschneiden von Objekten mit einer Schere!

� Mask R-CNN Vorteile

  • Pixel-Genauigkeit Exakte Objektgrenzen statt grober Bounding Boxes
  • Multi-Objekterkennung Mehrere Instanzen pro Bild erkennbar
  • Flexible Objektformen Auch unregelmäßige Formen perfekt erkannt
  • Qualitäts-Bewertung Confidence Scores für jede Erkennung

🧠 Wie funktioniert Mask R-CNN?

2-Stufen-Architektur: Erst werden Objektvorschläge generiert (RPN), dann wird jeder Vorschlag klassifiziert und eine pixel-genaue Maske erstellt.

ResNet50 + FPN: Das Backbone-Netzwerk extrahiert Features in verschiedenen Auflösungen für robuste Objekterkennung.

📊 Loss-Funktionen

  • Classification Loss: Cross-Entropy für Objektklassifikation
  • Box Regression Loss: Smooth L1 Loss für Bounding Box Koordinaten
  • Mask Loss: Binary Cross-Entropy für pixel-genaue Segmentation
  • RPN Loss: Objectness + Box Regression für Region Proposals
